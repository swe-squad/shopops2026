Scope / assumptions

This is a proposed viewer, not the existing implementation. It combines viewing space, not browser profiles or native emulators. Our two apps can allow this viewer to embed them; external sites inside the browser may still block embedding and need Open in new tab.

Glossary: frame = an independent web document displayed within a page; origin = protocol + host + port. No account or app data is shared by the viewer.
