# ShopOps web

A React workspace showing the shop operations dashboard and a mobile-style agent chat preview. The service is currently a standalone UI: shop data, agent messaging, and shop connection are not integrated yet. Navigation works locally; no metrics or messages are presented as live data.

Run `make ci` to install dependencies, lint, test, and build. Run `npm run dev` for local development. The production container listens on port 80 and requires no runtime API configuration.
